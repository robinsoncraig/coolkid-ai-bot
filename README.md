# CoolKid AI Bot

An Instagram-style AI assistant for auto-replies, captions, and DM support.
Built with Node.js and OpenAI API.

## Features
- Chat like Instagram AI
- Friendly tone, English + Sheng + emojis
- Short, engaging replies
- Ready to integrate with Instagram DMs

## Setup
1. Clone project
2. Run `npm install`
3. Create `.env` with your OpenAI API key
4. Run `node src/server.js`
5. Test via Postman or curl
